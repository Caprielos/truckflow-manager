# Requisiti del progetto

Questo documento descriverà i requisiti funzionali e non funzionali di TruckFlow Manager.

## Requisiti funzionali iniziali

- Il sistema deve permettere la gestione dei clienti.
- Il sistema deve permettere la gestione degli autisti.
- Il sistema deve permettere la gestione dei camion.
- Il sistema deve permettere la creazione e gestione delle spedizioni.
- Il sistema deve permettere di aggiornare lo stato di una spedizione.

## Requisiti non funzionali iniziali

- Il progetto deve essere sviluppato in Java 21.
- Il progetto deve usare una struttura compatibile con Maven.
- Il codice deve essere organizzato in modo leggibile e manutenibile.
- Il progetto deve essere documentato.
