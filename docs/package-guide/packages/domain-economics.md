# `domain/economics`

Costi, ricavi, IVA, acquisti flotta, fatture fornitori, utile/perdita e cassa/debito.

## Come leggerlo

Questo package contiene concetti o regole del business. Non dovrebbe dipendere da database, web o infrastructure.
