# Percorso didattico consigliato

Questa cartella è pensata per studiare il codice anche partendo da basi deboli.

## Ordine consigliato

1. `01-java-words-explained.md` — parole Java base: public, final, class, interface, record, static.
2. `02-how-to-read-a-class.md` — come leggere una classe riga per riga.
3. `03-interface-record-final-generics.md` — interfacce, record, final e generics spiegati piano.
4. `04-use-case-command-result.md` — use case, Command e ApplicationResult.
5. `05-ports-in-and-out.md` — port/in e port/out.
6. `06-repositories-and-memory.md` — repository e salvataggio in memoria.
7. `07-tests-for-beginners.md` — cosa sono i test.
8. `08-junit-assertions.md` — assertEquals, assertTrue, assertThrows.
9. `09-scenario-tests-explained.md` — test di scenario reali.
10. `10-debugging-maven-errors.md` — come leggere errori Maven.

## Obiettivo

Non imparare tutto a memoria. Devi imparare a fare queste domande:

```text
Che livello sto guardando?
Questa classe rappresenta dati o una regola?
È una porta o una implementazione?
Da dove arrivano gli input?
Dove viene salvato il risultato?
Quale test prova questa cosa?
```
