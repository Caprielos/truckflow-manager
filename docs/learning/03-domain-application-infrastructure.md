# 03 - Domain, application, infrastructure

## Domain

Risponde a domande del business:

```text
questa missione è valida?
questo carico richiede ADR?
questa missione è profittevole?
```

## Application

Esegue azioni complete:

```text
pianifica missione
assegna parcheggio
calcola payroll
registra movimento magazzino
```

## Infrastructure

Collega il sistema alla tecnologia:

```text
RAM
database
file
API esterne
```

Oggi esiste `infrastructure.memory`, cioè RAM. Domani potrà esistere `infrastructure.persistence`, cioè database.
