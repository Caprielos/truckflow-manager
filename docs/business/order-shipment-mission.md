# Differenza tra ordine, spedizione e missione

## Order

L’ordine è la richiesta commerciale del cliente.

Esempio:

```text
Cliente ACME chiede trasporto Milano → Roma per 5.000 kg.
```

## Shipment

La spedizione nasce quando l’ordine è accettato. Descrive cosa deve essere trasportato e con quali requisiti.

## TransportMission

La missione è il viaggio reale: autista, convoglio, rotta e stato operativo.

## Perché separarli

Un ordine può essere commerciale, una spedizione è logistica, una missione è operativa.

Questa separazione rende il modello più reale e riduce confusione.
