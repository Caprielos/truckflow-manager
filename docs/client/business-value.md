# Valore per il cliente

## Riduzione errori operativi

Il sistema separa chiaramente ordine, spedizione e missione. Questo riduce errori come assegnare un mezzo incompatibile o un autista non abilitato.

## Controllo economico

Il sistema distingue ricavi, costi, IVA, costo autista, acquisti e spese ricorrenti. Questo permette di capire se una missione è profittevole o se l'azienda sta generando perdita.

## Gestione flotta più realistica

Mezzi, rimorchi, gomme, manutenzione, carburante, parcheggi e depositi sono trattati come componenti diverse ma collegate.

## Preparazione a database/API

L’architettura è già impostata per aggiungere repository reali, API REST e integrazioni esterne.
