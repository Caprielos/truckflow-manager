# Class reference

Questa sezione aiuta a trovare le classi e capire cosa rappresentano.

- `all-classes-by-package.md` contiene l'elenco completo generato dal codice.
- I file `domain-*.md`, `application-explained.md` e `infrastructure-memory.md` spiegano le aree principali.

Nota: non tutte le classi hanno una spiegazione manuale lunghissima; dove il progetto ha molte enum o value object, la tabella indica tipo, scopo, campi e metodi principali.
