# ADR 001 - Utilizzo di Java 21

## Contesto

Il progetto deve essere sviluppato con una versione moderna e stabile di Java.

## Decisione

Il progetto userà Java 21 LTS tramite Eclipse Temurin JDK.

## Motivazioni

Java 21 è una versione LTS, quindi adatta a progetti professionali e di lungo periodo.

## Conseguenze

Il progetto richiederà Java 21 o superiore per essere compilato ed eseguito.
