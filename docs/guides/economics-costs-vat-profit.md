# Economics, costi, IVA e profitto

La parte economica distingue ricavi, costi, IVA e risultato.

## Ricavi

Le righe di ricavo missione rappresentano ciò che si chiede al cliente.

Esempi:

```text
trasporto base
supplemento ADR
supplemento frigo
supplemento attesa
supplemento urgenza
```

## Costi

Le righe di costo rappresentano quanto costa davvero svolgere la missione.

Esempi:

```text
carburante
pedaggi
autista
manutenzione
gomme
assicurazione
quota struttura
```

## IVA

L'IVA non va confusa con il guadagno.

```text
IVA incassata dal cliente
→ non è ricavo vero

IVA detraibile sugli acquisti
→ non è costo reale

IVA non detraibile
→ diventa costo
```

## Profitto

```text
profitto = ricavi netti - costi reali
```

`EconomicsRules` aiuta a capire se una missione è profittevole, in pareggio o in perdita.
