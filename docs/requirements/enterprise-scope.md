# Enterprise scope

## Visione

TruckFlow Manager vuole diventare un sistema TMS/FMS, cioè:

```text
Transport Management System + Fleet Management System
```

## Moduli principali

- CRM cliente e contratti.
- Ordini e spedizioni.
- Ufficio traffico.
- Flotta.
- Driver e payroll.
- Economics e contabilità gestionale.
- Depositi, parcheggi e magazzino.
- Documenti e compliance.
- Import dati esterni.
- Report e audit.

## Differenza rispetto a un gestionale semplice

Un gestionale semplice dice:

```text
camion X porta merce Y
```

TruckFlow Manager vuole dire:

```text
questa missione è fattibile, documentata, compatibile, tracciabile e redditizia
```

## Utenti previsti

- Admin.
- Dispatcher.
- Fleet manager.
- Accountant.
- Driver.
- Warehouse operator.
- Customer user.

## Dati sensibili

La futura app dovrà proteggere:

- stipendi;
- costi;
- margini;
- documenti;
- dati autista;
- dati cliente;
- fatture.
