# Assunzioni e confini del progetto

## Assunzioni

- Il progetto attuale è backend/domain-first.
- Non esiste ancora database reale.
- I repository in memoria servono per test e demo.
- Le regole fiscali precise devono diventare configurabili.

## Cosa non fa ancora

- Non espone API REST.
- Non ha frontend.
- Non persiste dati dopo lo spegnimento.
- Non genera PDF reali.
- Non si collega ancora a fuel card o telematica reali.

## Perché va bene così

Il progetto è stato costruito per fasi: prima domain, poi application, poi infrastructure, poi web/API e database.
