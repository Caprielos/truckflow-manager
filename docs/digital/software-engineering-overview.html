Executive Summary

Un sistema logistico enterprise costruito per layer

TruckFlow Manager è un progetto Java 21 per modellare processi logistici e di trasporto merci. Non nasce come semplice CRUD: prima stabilizza il dominio, poi i casi d’uso applicativi, poi gli adapter tecnici, e solo dopo introduce API REST.

Architettura

Separazione dei layer

API Layer Punto 8A formalizzato; controller, DTO, error handling e OpenAPI nei punti successivi.
Application Layer Use case, command, result, port in/out.
Domain Layer Business model puro, senza Spring/JPA/REST.
↔
Infrastructure Layer Spring wiring non-web, repository memory/file-backed, mapping.
Infrastructure implementa dettagli tecnici, ma non deve contaminare domain/application.
Regola principale: api → application → domain infrastructure → application/domain Vietato: domain → application/infrastructure/api application → infrastructure/api api → repository concreti

Glossario

Termini essenziali

Domain Layer

Layer con concetti e regole di business.

Application Layer

Layer dei casi d’uso e delle port.

Infrastructure Layer

Layer tecnico con adapter e repository concreti.

API Layer

Layer REST versionato: blueprint formalizzato in 8A, runtime nei punti successivi.

Port

Interfaccia applicativa di ingresso o uscita.

Adapter

Implementazione tecnica collegata a una port.
