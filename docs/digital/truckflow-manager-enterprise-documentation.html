TruckFlow Manager

Documentazione sintetica professionale dopo il completamento del Punto 7 — Infrastructure Layer.

Overview

TruckFlow Manager è un progetto Java 21 per la modellazione di una piattaforma di trasporto, logistica e gestione flotta, costruito con separazione tra Domain, Application e Infrastructure Layer.

Domain Layer

Contiene regole business, aggregate, value object, eccezioni e invarianti. È privo di dipendenze tecniche.

Application Layer

Contiene use case, command, result, port in, port out e service applicativi.

Infrastructure Layer

Contiene adapter tecnici, repository in-memory, repository file-backed, mapper, eccezioni e Spring wiring non-web.
