Stato attuale

TruckFlow Manager ha completato il Domain Layer, l'Application Layer e il primo ciclo Infrastructure Layer. Il prossimo ciclo sarà il Punto 8 — API Layer.

  • Nessun REST controller è ancora introdotto.
  • Nessun JPA o Spring Data è ancora introdotto.
  • Spring è usato solo come wiring tecnico non-web.
  • I repository file-backed restano limitati ai contesti validati nel Punto 7.
