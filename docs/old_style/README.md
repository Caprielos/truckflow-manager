# Archivio storico della documentazione

Questa cartella contiene la documentazione storica step-by-step di TruckFlow Manager.

I documenti numerati da `01` a `37` raccontano come il progetto è arrivato fino alla chiusura del **Punto 7 — Infrastructure Layer**.

Questa sezione non è la guida principale per iniziare. Per una lettura più chiara usa prima:

- [`../simple/README.md`](../simple/README.md) per capire il progetto con parole semplici;
- [`../professional/README.md`](../professional/README.md) per la documentazione tecnica ufficiale;
- [`../digital/index.html`](../digital/index.html) per la versione navigabile.

## Come leggere questo archivio

Leggilo quando vuoi ricostruire una decisione, una fase o uno step specifico della roadmap.
